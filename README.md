# CD2201-14 Elegir sin ver el futuro: Estrategias y Algoritmos Óptimos
Este repositorio contiene el material **computacional** del módulo interdisciplinario CD2201-14 Elegir sin ver el futuro: Estrategias y algoritmos óptimos.

El objetivo principal es reunir los códigos utilizados en cátedras, clases auxiliares y simulaciones, junto con ejemplos que ayuden a comprender y visualizar los algoritmos estudiados durante el curso :)
